# SDSS Star-Galaxy Classifier — project write-up

This repository contains a single-page GitHub Pages presentation for the Matter, Energy, Space, and Time project. The write-up text is presented as provided, with notebook code excerpts, a five-image histogram carousel, a filter-readings image, a dot plot, and an interactive 16-combination confusion-results display.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for the Pages URL to appear in the Pages settings.

## Add the image files

Create an `images/` folder in the repository and add these files. The attached images themselves are not uploaded by the site source, so add them with these filenames for them to appear:

- `01-ultraviolet.png`
- `02-green.png`
- `03-red.png`
- `04-near-infrared.png`
- `05-infrared.png`
- `06-dot-plot.png`
- `07-filter-readings.png`

The confusion matrix results are rendered as 16 interactive slides from the numbers in the write-up, so no separate confusion-matrix image is required.

The notebook data file used in the original analysis is not included here. The embedded code sections are excerpts from `MEST.ipynb`.
